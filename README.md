# HYB Card Dashboard

`card.gudong226.com` 的传说卡 90 天收益演算台。

## 本地开发

```bash
npm install
npm run build
npm run dev
```

网页源码位于 `site/`，Cloudflare Worker 静态资源构建到 `dist/`。

## 主题与导航

- 三态主题循环：跟随系统 → 暗色 → 亮色 → 跟随系统
- 顶栏 Farm 图标跳转到 [HYB Farm Dashboard](https://hyb.gudong226.com/)
- GitHub 入口指向 [GuDong2003/hyb-card-dashboard](https://github.com/GuDong2003/hyb-card-dashboard)
