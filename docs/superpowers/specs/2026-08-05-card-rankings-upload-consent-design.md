# 榜单脚本安装与上传授权设计

## 目标

让榜单统计页像 HYB Farm Dashboard 一样，明确提供脚本安装入口，并允许用户控制是否把新抓取的公开榜单快照上传到共享 D1；同时让油猴脚本在 Card 与 CDK 两个域名都能被识别，但不在 CDK 页面显示榜单 UI。

## 用户体验

- 榜单页顶部始终显示“安装同步脚本”入口，不再只在失败提示中出现。
- 同一区域显示“抓取后自动上传”开关，默认关闭，并保存在当前浏览器。
- 关闭自动上传时，页面仍会主动通过油猴脚本抓取榜单，但只在当前页面展示，不提交 D1。
- 抓取后存在未上传快照时，显示“上传本次快照”按钮；用户明确点击后才提交。
- 开启自动上传时，抓取成功后自动提交 D1，并刷新共享历史。
- 脚本完整保留接口返回的所有周期榜单：今日、本周、本月和赛季。
- 每个周期严格按同一 `userId` 配对 `epic_*` 与 `spend_*`，再按用户 `isVip` 反推抽数。
- 榜单展示以用户为主，使用一张用户总览表合并同周期欧皇榜、消费榜和兑换榜；默认整个赛季，顶部周期选择会重新计算和排序。消费、抽卡、兑换、出卡率缺失时对应单元格留空，不把缺失当成 0。

## 数据边界

- 油猴脚本匹配 `https://card.gudong226.com/*` 和 `https://cdk.hybgzs.com/*`，只向 CDK 榜单接口发起读取请求；CDK 页面不显示按钮或榜单 UI。
- 上传内容只包含公开榜单快照、赛季、榜单数值和采集时间。
- 关闭上传开关时，前端不得调用 `/api/rankings/snapshots`。
- 现有 D1 数据始终可读；上传设置不影响榜单浏览和历史搜索。
- 消费榜原始值按 `spend.value / 500000` 换算为 USD；VIP 使用每日 6000 USD / 650 抽，普通用户使用每日 4000 USD / 430 抽。
- 同周期配对榜单缺失时，概率标记为数据不完整，不将缺失值当成 0；消费金额不是完整日成本的整数倍时标记为估算值。

## 实现约束

- 使用 `localStorage` 保存上传偏好，键名为 `hyb-card-rankings-settings-v1`，默认 `autoUpload: false`。
- 复用现有榜单渲染逻辑；本地未上传快照需要在浏览器端转换为当前榜单行并标记为“本地未上传”。
- 不新增 URL 路由、不修改 `cdk.hybgzs.com` 页面、不增加新的主动轮询；双域脚本仅用于兼容油猴匹配和跨页面 relay。Card 页面优先请求已打开 CDK 页脚本，失败后才回退跨域请求，单次刷新不重复请求。

## 错误处理

- 未安装脚本或未登录 CDK 时，安装入口和登录说明保持可见。
- 自动上传失败时保留本地快照，并提示可稍后手动上传。
- 手动上传失败时不清空本地快照。
